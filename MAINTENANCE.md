# Maintained downstream

This repository is a fork of [CorentinTh/it-tools](https://github.com/CorentinTh/it-tools). Preserve the upstream MIT license and attribution. The initial maintained branch keeps upstream application code unchanged; the purpose is to provide a stable place for reviewed local fixes and a future server-delivered Nocturne Atlas theme.

Use the `upstream` remote for comparison and deliberately reviewed updates, not an unattended reset of downstream changes. Keep theme code separate from upstream components where possible. Check utility behavior, forms, focus and mobile layout when adding styles; low upstream release activity does not justify skipping initial verification.

Do not commit browser data, credentials, generated keys or local deployment configuration. Repository creation is not deployment; the running application remains unchanged.
